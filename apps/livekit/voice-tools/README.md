# Voice tools

Mu3Lab writes two files here for the voice agent, which mounts this folder read-only:

- `people.json` (`ctl/voice_tools.py`): each household member's app assistants, with their own
  ContextForge keys.
- `settings.json` (`ctl/voice_settings.py`): the household's choices in Settings, Voice assistant.

Nothing here is checked in except this note.
