# Task notes

One file per task (`<task>.md`, e.g. `0-1-grocy-fixes.md`): VERIFY findings with
evidence (image digest, command, result), decisions taken, and the acceptance
checklist with proof. Also kept here:

- `owner-permissions.md`: standing permissions the owner granted for this plan (e.g. pushing).
- `upstream-issues.md`: upstream bugs and the removable work-arounds for them.
- `future.md`: deliberately deferred ideas (per-person connector credentials, mobile push for approvals, …).
